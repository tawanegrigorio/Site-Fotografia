# Site de Fotografia

Projeto de desenvolvimento web criado para apresentar o trabalho de uma fotógrafa por meio de uma interface elegante, acolhedora e organizada.

## Sobre o projeto

O site foi desenvolvido para apresentar informações sobre a fotógrafa, seus serviços e pacotes, além de facilitar o contato com pessoas interessadas em realizar sessões fotográficas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Apresentação da fotógrafa.
- Exibição de pacotes fotográficos.
- Navegação entre as seções do site.
- Layout adaptado para diferentes tamanhos de tela.
- Seção de contato.
